# Notice

**This repository is intended to be PRIVATE.** It is public only for a limited period, to
use GitHub Actions compute, and will be made private again (see the Algorythmos catalog:
`intended_visibility: private`). Public visibility grants no licence. See [`LICENSE`](LICENSE).

## What is deliberately NOT in this repository while it is public
- No secrets of any kind. They live in GitHub Actions secrets and hosting environment settings.
- No patient, caller or clinic data. Tests and fixtures are synthetic only (see
  [`AGENTS.md`](AGENTS.md) §Data).
- No production clinic configuration: no real phone numbers, voice-agent IDs or practice rosters.
- No voice-agent prompts or conversation templates (trade secrets). They are added once the
  repository is private.
- No content copied from any private Algorythmos repository.

## Before making this repository private again
Follow the org runbook `docs/go-private.md` in `Algorythmos-AI/.github-private`.
